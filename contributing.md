# Contributing to Pirate Radio

Thank you for helping build an unstoppable, decentralized web infrastructure!

## How to Contribute

1. **Report Bugs:** Open an Issue detailing your operating system, setup, and steps to reproduce.
2. **Propose Features:** Ideas for new transport adapters (e.g., LoRa, sound card modems) or performance improvements are always welcome. Submit a Feature Request issue first to discuss the design.
3. **Submit Code:**
   - Fork the repository.
   - Create a feature branch (`git checkout -b feature/my-adapter`).
   - Write tests for your feature.
   - Ensure all tests pass (`cargo test`).
   - Open a Pull Request pointing to `main`.

## Code of Conduct

Be respectful, keep conversations focused on building resilient tech, and remember that Pirate Radio belongs to everyone.
